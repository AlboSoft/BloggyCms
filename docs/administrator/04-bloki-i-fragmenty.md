# 🧱 Блоки и фрагменты

Три инструмента, из которых собирается внешний вид сайта:

| Инструмент | Что это | Где живёт |
|---|---|---|
| **HTML-блоки** | Готовые секции страницы: шапка, подвал, hero, слайдер, «последние посты» | `/admin/html-blocks` |
| **Пост-блоки** | «Кирпичики» внутри постов и страниц: текст, картинка, галерея, код | `/admin/post-blocks` |
| **Фрагменты** | Переиспользуемые сущности контента со своими полями и записями | `/admin/fragments` |

---

## HTML-блоки

HTML-блок — это именованная секция, которая выводится в теме по «слоту». Адрес блока — `slug` (например, `header`), и именно по нему тема запрашивает блок: `render_html_block('header')`.

### Стандартные слоты темы по умолчанию

| Slug | Где появляется |
|---|---|
| `header` | Шапка сайта: логотип, меню |
| `breadcrumbs` | Хлебные крошки |
| `footer` | Подвал: контакты, копирайт, ссылки |
| `top` | Кнопка «наверх» и прочие мелкие элементы |
| `cookies` | Уведомление о cookie |

Можно создать и другие блоки — например, `sidebar` или `promo`, — и вывести их в шаблоне страницы, если вы умеете править тему (см. [Тема и оформление](10-tema.md)).

### Типы HTML-блоков

В поставке 12 готовых типов + «произвольный HTML»:

| Тип | Что выводит |
|---|---|
| `DefaultHeaderBlock` | Шапка: логотип, название, ссылка, меню |
| `DefaultFooterBlock` | Подвал: логотип, текст, колонки ссылок |
| `DefaultHeroBlock` | Первый экран: заголовок, кнопки, картинка |
| `DefaultLatestPostsBlock` | Лента последних постов |
| `DefaultServicesBlock` | Блок услуг/преимуществ с повторителем |
| `CategoriesListBlock` | Список категорий |
| `TagsBlock` | Облако тегов |
| `PageTreeBlock` | Дерево страниц |
| `AuthorBlock` | Карточка автора |
| `DefaultBreadcrumbsBlock` | Хлебные крошки |
| `CookieConsentBlock` | Плашка согласия на cookie |
| `ScrollToTopBlock` | Кнопка «наверх» |
| `DefaultBlock` | Произвольный HTML с шорткодами |

### Как создать блок

1. **Контент-блоки → Создать**, выберите тип из списка (`admin/html-blocks/select-type`).
2. Заполните **название** и **slug** — по slug тема будет искать блок.
3. Настройте параметры типа: у шапки это логотип и ссылка, у hero — заголовок, кнопки и картинка, у списка постов — сколько и каких постов показывать.
4. При необходимости выберите **шаблон вывода** (если у типа есть варианты) и добавьте свои CSS/JS.
5. Сохраните и проверьте сайт.

### Управление типами

`/admin/html-blocks/types` — список типов блоков с возможностью включать/выключать (`types/toggle/{systemName}`) и удалять пользовательские (`types/delete/{systemName}`). Встроенные типы защищены.

### Кеш

Блоки кешируются в CSS/JS для скорости. После правок нажмите **«Очистить кеш блоков»** (`admin/html-blocks/clear-cache`) — движок пересоберёт стили и скрипты блоков.

> [!TIP]
> Для простых текстовых вставок не создавайте новый тип — используйте `DefaultBlock`. Он принимает произвольный HTML и обрабатывает шорткоды (`{fragment:...}`, поля, меню).

## Пост-блоки

Пост-блоки — это элементы блочного редактора. Вы не создаёте их вручную для каждого поста: вы **редактируете сами типы** — как они выглядят, какие настройки предлагают, что разрешено.

`/admin/post-blocks` — список типов:

| Тип | Для чего |
|---|---|
| Текст | Основной абзац |
| Заголовок | H2–H4 внутри материала |
| Изображение | Одиночная картинка |
| Изображение с текстом | Двухколоночный блок |
| Галерея | Набор изображений |
| Видео | Вставка по ссылке |
| Аудио | Аудиоплеер |
| Цитата | Выделенная цитата с автором |
| Список | Маркированный/нумерованный |
| Код | Блок кода с подсветкой |
| Алерт | Информационное/предупреждающее сообщение |
| Кнопка | Кнопка со ссылкой |
| Спойлер | Скрытый текст |
| Произвольный HTML | Вставка кода |
| Пост | Вставка другого поста |
| Контентный блок | Вставка HTML-блока |

### Что можно настроить у типа

- включать блок **для постов** и/или **для страниц** (`enable_in_posts`, `enable_in_pages`);
- **шаблон вывода** — как блок рендерится на сайте;
- собственные CSS/JS для админки и фронтенда;
- набор полей в форме редактирования блока;
- **пресеты** — готовые варианты настроек, чтобы автор выбирал один клик.

> [!WARNING]
> Правка шаблона пост-блока влияет на **все** посты, где он использован. Если нужно менять вид одного материала — используйте HTML-блок или настройки конкретного блока в посте.

### Когда создавать свой пост-блок

Если нужен новый повторяющийся элемент контента (например, «Сравнительная таблица» или «Шаги установки»). Это уже задача для разработчика — см. [Пост-блоки](../developer/07-post-bloki.md).

## Фрагменты

Фрагмент — это собственная сущность контента со своей структурой. Примеры: «Отзывы», «Партнёры», «Вопросы и ответы», «Команда».

### Как устроен фрагмент

1. **Фрагмент** — имя, системное имя (`system_name`), описание, собственные CSS/JS.
2. **Поля фрагмента** — какие данные хранит запись (текст, картинка, ссылка, число…).
3. **Записи** — конкретные значения: «Иван Иванов, фото, должность».

### Создание

1. **Фрагменты → Создать**: задайте название и системное имя (латиницей, например `reviews`).
2. Войдите в **«Поля»** фрагмента и опишите структуру записи.
3. Добавьте **записи** (`entries`) с данными.
4. Выведите фрагмент в теме или в HTML-блоке.

### Вывод

| Синтаксис | Что делает |
|---|---|
| `{fragment:reviews}` | Выводит фрагмент со стандартным шаблоном |
| `{reviews}` | То же самое, короткая форма |
| `{ctype:reviews}свой шаблон{/ctype:reviews}` | Выводит фрагмент, используя HTML внутри тега как шаблон |

Фрагменты можно вставлять в HTML-блоки, страницы, посты и описания меню — везде, где обрабатываются шорткоды.

> [!TIP]
> Фрагмент — лучший способ дать редактору управлять структурными данными, не давая доступ к шаблонам. Например: отзывы, тарифы, команда, партнёры, FAQ.

---

## Что выбрать?

| Задача | Решение |
|---|---|
| Шапка, подвал, cookie-плашка | HTML-блок (слот темы) |
| Повторяющийся элемент внутри статьи | Пост-блок |
| Список данных с одинаковой структурой | Фрагмент |
| Разовая вставка кода в одном посте | Пост-блок «Произвольный HTML» |
| Секция, которую редактор собирает сам | HTML-блок типа `DefaultBlock` |
