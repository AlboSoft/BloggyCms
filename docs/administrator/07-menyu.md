# 🧭 Меню сайта

Меню в BloggyCMS собирается визуально: вы создаёте меню, добавляете пункты, вкладываете их друг в друга и указываете, в каком шаблоне выводить — например, в шапке или подвале.

Раздел: **Меню** (`/admin/menu`).

---

## Создание меню

1. **Меню → Создать** (`/admin/menu/create`).
2. Заполните:

| Поле | Что значит |
|---|---|
| **Название** | Внутреннее имя: «Главное меню», «Меню подвала» |
| **Шаблон вывода** | К какому месту темы привязать меню (`header`, `footer` и т. д.) |
| **Настройки видимости** | Кому показывать: гостям, пользователям, админам |
| **Свой шаблон** | Если нужно своё оформление вёрстки — включите `use_custom_template` и вставьте разметку |

3. Сохраните меню и перейдите к пунктам (`/admin/menu/items/{id}`).

Меню может быть несколько: «Главное» для шапки, «Информация» для подвала, «Личное» для авторизованных.

---

## Пункты меню

| Действие | Адрес |
|---|---|
| Добавить пункт | `/admin/menu/item/create/{menuId}` |
| Редактировать | `/admin/menu/item/edit/{id}` |
| Удалить | `/admin/menu/item/delete/{id}` |
| Изменить порядок | `/admin/menu/reorder` |
| Предпросмотр | `/admin/menu/preview/{id}` |

### Что заполняется в пункте

| Поле | Описание |
|---|---|
| **Название** | Текст ссылки |
| **Ссылка** | Адрес: внутренний (`/posts`, `/category/news`) или внешний (`https://example.com`) |
| **Родитель** | Для вложенности: пункт второго уровня |
| **Порядок** | Позиция среди соседей |

Порядок меняется перетаскиванием. Пункты со вложенными элементами автоматически получают разметку выпадающего списка (в стандартной теме).

## Подстановки (шорткоды) в ссылках

В адресе пункта можно использовать динамические подстановки — ссылка меняется в зависимости от того, кто смотрит сайт:

| Шорткод | Значение |
|---|---|
| `{user_id}` | ID пользователя |
| `{username}` | Логин |
| `{email}` | E-mail |
| `{first_name}`, `{last_name}` | Имя и фамилия из профиля |
| `{display_name}` | Отображаемое имя |
| `{slug}` | Slug пользователя (для ссылки на профиль) |
| `{base_url}` | Адрес сайта |
| `{admin_url}` | Адрес админки |
| `{site_name}` | Название сайта |
| `{year}`, `{month}`, `{day}` | Текущие дата и время |
| `{user_field:имя_поля}` | Значение пользовательского поля пользователя |

**Пример.** Пункт «Мой профиль» со ссылкой `/profile/{slug}` покажет у гостя ссылку на вход, а у пользователя — на его профиль.

## Видимость меню и пунктов

- **Настройки видимости** позволяют скрыть меню для гостей или, наоборот, показать только им.
- Пункт с незаполненной ссылкой используется как **заголовок группы** — он не кликабелен, но его дети раскрываются.

> [!TIP]
> Типовые меню: **Главная · Посты · Категории · О сайте · Контакты** в шапке и **О проекте · Политика конфиденциальности · RSS · Контакты** в подвале. Не пытайтесь сложить в шапку 15 пунктов — сделайте категории подменю.

## Вывод в теме

Движок рендерит меню несколькими способами:

```php
<?php
// По шаблону (значение поля «Шаблон вывода»)
echo MenuRenderer::renderByTemplate('header');

// По имени меню (название, что вы дали в админке)
echo render_menu_by_name('Главное меню');

// По ID
echo render_menu_by_id(1);

// Все меню, привязанные к шаблону
echo MenuRenderer::renderAllByTemplate('footer');
```

Чаще всего меню уже выведено в стандартных HTML-блоках (`DefaultHeaderBlock`, `DefaultFooterBlock`): там достаточно выбрать меню в настройках блока. Отдельный вызов нужен, только если вы правите тему.

---

## Проверка работы

1. Меню сохранено и привязано к шаблону, который реально выводится темой.
2. Все ссылки открываются (проверьте и внутренние, и внешние).
3. Вложенные пункты раскрываются на телефоне.
4. Динамические шорткоды проверены в двух состояниях: гость и авторизованный.
5. Меню не дублируется: если оно уже выводится в HTML-блоке, не вызывайте его повторно в шаблоне.
