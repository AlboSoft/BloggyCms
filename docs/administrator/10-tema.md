# 🎨 Тема и оформление

Внешний вид сайта задаёт **тема**. В поставке одна тема — `default`, и её достаточно, чтобы запустить блог: она адаптивная, с готовыми шаблонами страниц и блоков. Переключение темы и правка файлов делаются прямо из админки.

---

## Из чего состоит тема

```
templates/default/
├── front/                      # публичная часть сайта
│   ├── layout.php              # общий каркас: <head>, шапка, подвал, подключение CSS/JS
│   ├── home/                   # главная страница
│   ├── posts/                  # лента, карточка поста
│   ├── pages/                  # страницы
│   ├── category/               # страницы категорий
│   ├── tags/                   # страницы тегов
│   ├── archive/                # архив
│   ├── search/                 # результаты поиска
│   ├── profile/                # профиль пользователя
│   ├── auth/                   # вход, регистрация, восстановление пароля
│   ├── comments/               # шаблоны комментариев
│   ├── users/                  # списки пользователей
│   └── assets/
│       ├── css/main.css        # основные стили темы
│       ├── js/                 # скрипты темы
│       ├── html_blocks/        # шаблоны HTML-блоков
│       ├── postblocks/         # шаблоны пост-блоков
│       ├── forms/              # шаблоны форм (modern, minimal, iconic)
│       └── menu/               # шаблоны меню
├── admin/                      # панель управления
│   ├── layout.php              # каркас админки
│   └── assets/                 # CSS/JS/иконки админки
├── 404.php                     # страница «не найдено»
└── 500.php                     # страница ошибки сервера
```

**Ключевой файл фронтенда — `front/layout.php`.** В нём подключаются CSS/JS, выводятся слоты HTML-блоков (`render_html_block('header')`, `'footer'`, `'breadcrumbs'`, `'top'`, `'cookies'`) и вставляется контент страницы.

---

## Переключение темы

**Настройки → Сайт → Тема оформления** (`site_template`).

Тема должна лежать в `/templates/<имя_темы>/`. Пока тема одна — значение `default`.

> [!NOTE]
> Админка всегда использует тему `default`. Менять её оформление переключением `site_template` нельзя — это отдельная папка `templates/default/admin`.

---

## Редактор шаблонов

Раздел **Шаблоны** (`/admin/templates`) — файловый редактор темы прямо в браузере:

| Действие | Маршрут |
|---|---|
| Список файлов темы | `/admin/templates/get-files` |
| Открыть файл | `/admin/templates/get-file` |
| Сохранить | `/admin/templates/save` |
| Скачать | `/admin/templates/download-file` |
| Загрузить | `/admin/templates/upload-file` |
| Создать папку в теме фронта | `/admin/templates/create-front-folder` |

### Бэкапы — включите обязательно

Перед правками включите **Настройки → Сайт → Резервные копии файлов шаблонов** (`template_backups_enabled`). При каждом сохранении движок создаёт копию файла вида `main.css.backup.2026-05-05-12-30-00`. Количество копий ограничивается `template_backups_count`, старые удаляются автоматически (`template_backups_cleanup`), а очистить всё сразу можно кнопкой на странице настроек.

> [!WARNING]
> Редактор шаблонов — инструмент администратора. Одна опечатка в `front/layout.php` уронит сайт. Работайте с бэкапами и держите под рукой FTP или доступ к файлам.

## Что и где менять

| Хочу изменить | Файл / раздел |
|---|---|
| Логотип и меню в шапке | HTML-блок `header` (Контент-блоки) — код трогать не нужно |
| Подвал: контакты, копирайт | HTML-блок `footer` |
| Цвета и типографику | `front/assets/css/main.css` |
| Отступы и сетку страницы поста | `front/posts/show.php` + `main.css` |
| Внешний вид списка постов | `front/posts/index.php`, `front/home/*` |
| Страницу «Не найдено» | `404.php` |
| Текст письма восстановления пароля | `system/languages/<локаль>/helpers.php` (`LANG_ACTION_AUTH_RESETPASSWORD_EMAIL_*`) |
| Мелкие скрипты | `front/assets/js/`, через `front_js()` |

> [!TIP]
> Начните с HTML-блоков и настроек — 80 % оформления меняется без правки файлов. Редактор шаблонов нужен только для структурных изменений.

## Своя тема: пошагово

1. **Скопируйте** папку `templates/default` в `templates/my-theme`.
2. Правьте файлы новой темы: `front/layout.php`, `front/assets/css/main.css`, шаблоны страниц.
3. Убедитесь, что в теме есть обязательные файлы: `front/layout.php`, `404.php`, `500.php`.
4. Переключите тему: **Настройки → Сайт → Тема оформления** → ваша тема.
5. Проверьте все типы страниц: главная, пост, страница, категория, тег, поиск, профиль, вход.
6. Проверьте адаптивность и скорость.

**Правила совместимости темы:**

- используйте функции движка (`render_html_block()`, `base_front_css()`, `render_front_css()`), а не «сырые» ссылки на файлы;
- выводите слоты HTML-блоков — иначе редактор не сможет управлять шапкой и подвалом;
- не удаляйте `init_blocks_cache()` в начале `layout.php` — от него зависит кеш стилей блоков;
- экранируйте вывод через `html()`.

> [!NOTE]
> Обновление движка не затрагивает вашу тему: файлы в `templates/` не перезаписываются. Но если меняется API шаблонов, может потребоваться адаптация — следите за примечаниями к релизам.

## Шаблоны блоков

У HTML-блоков и пост-блоков есть собственные шаблоны:

- `front/assets/html_blocks/<SystemName>/` — варианты разметки HTML-блока;
- `front/assets/postblocks/<имя_блока>/` — варианты разметки пост-блока.

Их можно переопределять в своей теме: движок ищет шаблон сначала в активной теме, потом в `default`. Выбор конкретного шаблона для блока делается в его настройках (поле «Шаблон»).

---

## Чек-лист после правок оформления

1. Сайт открывается, шапка и подвал на месте.
2. Все типы страниц проверены на телефоне и десктопе.
3. Ничего не «поехало» в постах с галереями, кодом и таблицами.
4. Бэкапы шаблонов включены, последняя правка сохранена.
5. Производительность не просела: тяжёлые шрифты и картинки оптимизированы.
