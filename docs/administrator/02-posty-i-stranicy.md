# ✍️ Посты и страницы

**Пост** — это материал в ленте: он попадает в список постов, категории, теги, архивы, RSS и закладки. **Страница** — это статический раздел («О сайте», «Контакты», «Политика конфиденциальности»), у неё есть иерархия и собственные блоки.

Разница на практике:

| | Пост | Страница |
|---|---|---|
| Адрес | `/post/{slug}` | `/page/{slug}` |
| Категории и теги | Да | Нет |
| Комментарии | Да (если разрешены) | Нет |
| Иерархия (родитель/потомок) | Нет | Да |
| Лента, RSS, архивы | Да | Нет |
| Редактор | Блочный | Блочный |

---

## Список постов

`/admin/posts` — таблица со всеми материалами: заголовок, категория, автор, статус, дата, просмотры, лайки, комментарии.

- Фильтры и поиск — по статусу, категории, автору.
- Быстрое переключение **черновик ⇄ опубликован** прямо в списке.
- Удаление с подтверждением.
- Счётчик постов и черновиков на дашборде включается в **Настройках → Админ-панель** (`show_drafts`, `count_posts`).

## Создание поста

Кнопка **«Добавить пост»** на дашборде или `/admin/posts/create`. Форма состоит из четырёх смысловых блоков.

### 1. Основное

| Поле | Что это |
|---|---|
| **Заголовок** | Название материала. Из него генерируется `slug`. |
| **Краткое описание** | Анонс для ленты, поиска и соцсетей. Используется в шаблонах как `short_description`. |
| **Slug** | Адрес поста: `/post/moy-post`. Латиница, цифры, дефисы. |
| **Категория** | Один раздел. Если не выбрать — пост попадёт в общую ленту. |
| **Теги** | Через запятую или выбором из существующих. |
| **Статус** | `draft` (черновик) или `published`. Черновики не видны гостям. |
| **Дата и время** | Можно указать свою — удобно для отложенной публикации (пост выйдет, когда наступит дата). |

### 2. Обложка (Featured Image)

- Загрузка изображения — `admin/posts/upload-featured-image`.
- **Показывать в списке** (`show_cover_in_list`) — выводить картинку в ленте.
- **Показывать в посте** (`show_cover_in_post`) — выводить картинку в начале материала.

> [!TIP]
> Загружайте обложку шириной 1200–1600 px и весом до 300–400 КБ. Это ускоряет сайт и не ломает вёрстку ленты.

### 3. Контент — блочный редактор

Тело поста собирается из **пост-блоков**: текст, заголовок, картинка, «картинка с текстом», галерея, видео, аудио, цитата, список, код, алерт, кнопка, спойлер, произвольный HTML, вставка другого поста и переиспользуемый контентный блок.

- Блоки перетаскиваются мышью, порядок сохраняется в таблице `post_blocks`.
- У каждого блока есть настройки (выравнивание, отступы, цвета, размеры — зависит от типа).
- Кнопка **«Просмотр»** показывает, как блок будет выглядеть на сайте.
- Для типовых решений есть **шаблоны блоков** (пресеты).

> [!NOTE]
> Почему не WYSIWYG? Блочный редактор хранит структуру, а не «случайный HTML». Это даёт предсказуемый вывод на любых устройствах, чистую разметку для SEO и возможность менять оформление блоков централизованно — в теме.

### 4. SEO и приватность

| Поле | Назначение |
|---|---|
| **SEO Title** | Заголовок для поисковиков (если пусто — берётся заголовок). |
| **Meta Description** | Описание для сниппета и соцсетей. |
| **Meta Keywords** | Ключевые слова (используйте умеренно). |
| **Пароль на пост** | Пост откроется только после ввода пароля (`post/check-password`). |
| **Контент 18+** | Включает возрастной барьер (`post/check-age`). Поведение настраивается в **Настройках → Посты**: `adult_content_action` (`none` / `age_check` / `redirect_login`) и `adult_min_age`. |
| **Показывать группам** | Список групп, которым пост виден. |
| **Скрывать от групп** | Список групп, которым пост не показывается. |
| **Разрешить комментарии** | Показывать форму обсуждения под материалом. |

Доступ к видимости по группам регулируется правами `post_view`, `post_comments`, `post_rating`, `post_favorites`.

### 5. Пользовательские поля

Если для сущностей типа `post` созданы свои поля (раздел **Поля**), они появятся в этом же окне — блок «Пользовательские поля». Значения полей выводятся в теме через шорткод `{post_имя_поля}` или хелперы `get_custom_field_value()` / `get_custom_field_display()`.

## Страницы

`/admin/pages` → **«Добавить страницу»**.

| Поле | Что это |
|---|---|
| **Заголовок** | Название страницы. |
| **Slug** | Адрес `/page/{slug}`. Кнопка «Сгенерировать» рядом. |
| **Родительская страница** | Иерархия: «Контакты» может лежать внутри «О компании». |
| **Статус** | Черновик / опубликована. |
| **Контент** | Те же блоки, что и в постах. |
| **Пользовательские поля** | Если созданы для типа `page`. |

> [!TIP]
> Для страниц удобно использовать **HTML-блоки** — например, форму обратной связи или карту. Блок можно вставить в страницу через блочный редактор или добавить в шаблон страницы.

Адреса страниц выводятся в **дерево страниц** HTML-блоком `PageTreeBlock` и в меню через конструктор меню.

## Публикация и продвижение внутри сайта

1. Проверьте **настройки ленты**: сколько постов на странице (`homepage_posts_per_page`) и что показывать на главной — настроенный шаблон главной или список постов (`homepage_type` в **Настройках → Посты**).
2. Добавьте пост в **меню** или в **HTML-блок «Последние посты»**, если он не должен теряться.
3. Проверьте, что категория и теги заполнены — это влияет на архивы `/archive`, `/category/{slug}`, `/tag/{slug}`.
4. Откройте пост на сайте и проверьте отображение на телефоне (тема адаптивная, но ваш контент — забота ваша).

## Частые вопросы

**Пост не виден на сайте.** Проверьте статус (`published`), дату публикации и ограничения — пароль, 18+, видимость по группам.

**Как изменить адрес (slug) у опубликованного поста?** Откройте пост и смените slug. Настройте редирект на уровне сервера, если материал уже проиндексирован, либо оставьте как есть — структура ссылок гибкая.

**Где включить отложенную публикацию?** Поставить дату в будущем и оставить статус «опубликован» — в ленте материал появится по наступлении даты.

**Можно ли вставить видео с внешнего хостинга?** Да — блоком «Видео» (поддерживается вставка по ссылке) или HTML-блоком с кодом встройки.
