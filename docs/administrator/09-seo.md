# 🔍 SEO

Раздел **SEO** (`/admin/seo`) закрывает базовую поисковую оптимизацию без сторонних плагинов: мета-теги, sitemap, RSS, robots.txt, микроразметка Schema.org и мгновенная индексация через IndexNow.

---

## Что генерируется автоматически

| Файл / адрес | Что внутри | Маршрут |
|---|---|---|
| `sitemap.xml` | Карта сайта: посты, страницы, категории, теги | `/sitemap.xml` |
| `rss.xml` | Основная лента | `/rss.xml` |
| Лента категории | Посты выбранной категории | `/rss/category/{slug}` |
| Лента тега | Посты с тегом | `/rss/tag/{slug}` |
| `robots.txt` | Правила для поисковых роботов | `/robots.txt` |

Файлы **пересобираются сами** при событиях контента: создан/изменён/удалён пост, страница, категория или тег. Это делает модуль `seo` через хуки (`post.created`, `post.updated`, `page.created` и т. д.).

> [!TIP]
> Если файлы не обновляются, проверьте права на запись в корень сайта: движок физически перезаписывает `sitemap.xml` и `rss.xml`.

## Мета-теги

Вкладка **«Настройки»** (`/admin/seo/settings`) управляет группой `seo_meta`:

| Настройка | Что делает |
|---|---|
| `default_title`, `default_description`, `default_keywords` | Мета по умолчанию для страниц без своих значений |
| `canonical_enabled` | Включать канонический URL на страницах |
| `include_images` | Добавлять изображения в sitemap |
| `include_full_content` | Полный контент в RSS вместо анонсов |

Отдельные значения задаются в карточках сущностей: у поста — **SEO Title**, **Meta Description**, **Meta Keywords**; у категории — meta-поля, canonical и флаг **noindex**.

Приоритет значений: мета сущности → шаблон/настройка → общий default.

> [!WARNING]
> Не дублируйте один и тот же `meta_description` на всех страницах — поисковики это не любят. Заполняйте описания для ключевых материалов и категорий.

## Вкладка Sitemap

Группа настроек `seo_sitemap`:

| Настройка | Значение |
|---|---|
| `enabled` | Включить карту сайта |
| `include_posts` / `include_pages` / `include_categories` / `include_tags` / `include_users` | Что включать |
| `categories_enabled`, `categories_priority` | Категории и их приоритет |
| `change_frequency_posts` / `_pages` / `_categories` / `_tags` | Как часто меняется контент |
| `max_posts` | Ограничение количества материалов в карте |
| `crawl_delay` | Рекомендуемая задержка для роботов |
| `indexnow_ping` | Уведомлять IndexNow при обновлении |

Адрес карты добавьте в `robots.txt` (он там уже прописан по умолчанию) и в Search Console / Яндекс.Вебмастер.

---

## Вкладка RSS

Группа `seo_rss`:

- включение ленты;
- заголовок и описание канала;
- количество элементов;
- полный текст или анонс (`include_full_content`);
- изображения в ленте.

Лента пригодится читателям с RSS-ридерами и сервисам автоматической рассылки.

---

## Вкладка robots.txt

Группа `seo_robots`:

| Настройка | Значение |
|---|---|
| `disallow_paths` | Закрытые разделы (админка, служебные маршруты) |
| `allow_paths` | Явно разрешённые пути |
| `crawl_delay` | Задержка обхода |
| `host` | Основной хост |
| `sitemap` | Ссылка на карту сайта |

> [!WARNING]
> В `disallow_paths` обязательно должны быть `/admin`, `/system`, `/install` и `/uploads/temp_addon`. Индексировать служебные страницы нельзя.

## Вкладка Schema.org

Микроразметка (`seo_schema`) помогает поисковикам понимать содержимое:

- тип страницы и организации;
- логотип, контакты, телефон, e-mail;
- авторы, даты публикации и обновления;
- изображения материалов.

Разметка подключается в теме автоматически, если заполнена (`layout.php` выводит `application/ld+json`).

## IndexNow — мгновенная индексация

IndexNow сообщает поисковикам (Яндекс, Bing и другие партнёры), что страница обновилась, — без ожидания обхода.

| Настройка | Что делает |
|---|---|
| `key` | Ваш ключ. Движок отдаёт его файлом по адресу `/{key}.txt` |
| `auto_submit` | Отправлять адреса автоматически при публикации |
| `bing_key` | Отдельный ключ Bing (если требуется) |
| `cron_token` | Секретный токен для обработки очереди |

**Как включить:**

1. Откройте вкладку **IndexNow**, сгенерируйте ключ.
2. Проверьте, что файл ключа открывается: `https://ваш-сайт/{key}.txt`.
3. Включите `auto_submit`.
4. Нажмите **«Проверить IndexNow»** (`admin/seo/test-indexnow`) — движок отправит тестовый адрес.

**Очередь отправки.** Адреса не улетают мгновенно: они складываются в `queue_tasks`, а обработчик `admin/seo/process-queue` разбирает её. Настройте вызов по расписанию (cron) с токеном:

```bash
# Раз в 15 минут разбираем очередь IndexNow
*/15 * * * * curl -s "https://ваш-сайт/admin/seo/process-queue?token=ВАШ_CRON_TOKEN" > /dev/null
```

> [!NOTE]
> Очередь позволяет не «дёргать» поисковики на каждую правку: адреса накапливаются и отправляются одним пакетом.

## Кеш SEO

Кнопка **«Очистить кеш SEO»** (`/admin/seo/clear-cache`) сбрасывает кешированные мета-данные и карты. Кеш ускоряет сайт, но иногда мешает видеть свежие правки:

- `cache_enabled` — включён ли кеш;
- `cache_lifetime` — сколько секунд живёт запись.

Если после правки описания на сайте старое значение — очистите кеш и повторите.

---

## Чек-лист SEO перед запуском

1. В **Настройках → Общие** заполнены `site_name`, `site_description`, `meta_keywords`.
2. В **SEO → Настройки** заданы meta по умолчанию и включён canonical.
3. `sitemap.xml` открывается и содержит все разделы.
4. `robots.txt` закрывает служебные пути и ссылается на карту.
5. RSS-лента работает.
6. У ключевых постов и категорий заполнены заголовки и описания.
7. Настроен IndexNow и (при желании) cron для очереди.
8. Сайт добавлен в Яндекс.Вебмастер и Google Search Console.
