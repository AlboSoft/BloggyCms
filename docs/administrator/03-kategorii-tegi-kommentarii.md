# 🗂️ Категории, теги и комментарии

Эти три раздела определяют структуру сайта и общение с читателями. Настраиваются они полностью из админки.

---

## Категории

`/admin/categories` — разделы сайта. Категория — это «полка»: она группирует посты, имеет собственный адрес `/category/{slug}`, может содержать подкатегории и закрываться паролем.

### Что заполняется при создании

| Поле | Зачем |
|---|---|
| **Название** | Видимое имя категории. |
| **Slug** | Адрес раздела: `/category/tekhnologii`. |
| **Описание** | Текст на странице категории и в мета-описании. |
| **Изображение** | Обложка раздела (`admin/categories/upload-image`). |
| **Meta Title / Meta Description** | Свои мета-теги вместо автоматических. |
| **Canonical URL** | Канонический адрес, если страница должна ссылаться на другой URL. |
| **Noindex** | Запрет индексации этой категории. |
| **Сортировка** | Порядок в списках и меню (перетаскивание и поле `sort_order`). |
| **Пароль** | Категория откроется только после ввода пароля (проверка `category/check-password/{id}` для AJAX-формы). |

### Подсказки

- 💡 **Держите 5–9 категорий.** Слишком много разделов размывают структуру и SEO.
- 💡 **Описания категорий** — хорошая точка для поиска: 2–3 предложения с ключевыми словами.
- 💡 **Удаление категории** не удаляет посты: движок предложит перенести их в другую категорию или оставить без категории.
- ⚠️ **Пароль на категорию** — не защита от серьёзной угрозы, а способ скрыть раздел от случайных глаз и поисковиков.

Настройки поведения категорий живут в **Настройках → Категории** (контроллер `categories`): раскладка (`category_layout`), количество записей (`categories_per_page`), показ изображений и описаний, показ количества постов, порядок сортировки (`categories_order`) и т. д.

## Теги

`/admin/tags` — метки внутри постов. Тег не создаёт иерархию, зато помогает читателю переходить по смежным материалам: `/tag/{slug}`.

| Возможность | Подробности |
|---|---|
| Название и slug | Уникальные; slug при желании латиницей |
| Изображение | Картинка тега для виджетов и списков |
| Описание | Текст на странице тега |
| Поиск | Быстрый поиск по тегам в админке (`admin/tags/search`) |
| Создание на лету | Теги можно создавать прямо из формы поста (`admin/tags/create-ajax`) |

Настройки показа тегов — в **Настройках → Теги** (`cont_tags_in_front` — сколько тегов выводить на фронтенде и как).

> [!TIP]
> Теги лучше работают как «жанры»: 3–6 меток на пост, без синонимов вроде «php» и «PHP-разработка». Синонимы дробят страницы тегов и мешают SEO.

## Комментарии

`/admin/comments` — обсуждения под постами. Комментарии поддерживают ответы (вложенность), статусы и модерацию.

### Управление

| Действие | Адрес | Примечание |
|---|---|---|
| Список и фильтры | `/admin/comments` | По статусу, посту, пользователю |
| Правка | `/admin/comments/edit/{id}` | Текст, автор, статус |
| Одобрение | `/admin/comments/approve/{id}` | Публикация отложенного |
| Удаление | `/admin/comments/delete/{id}` | Безвозвратно |

Пользователи тоже могут править и удалять свои комментарии — если им это разрешено правами:

| Право | Что даёт |
|---|---|
| `comment_add` | Писать комментарии |
| `comment_add_no_moderations` | Писать без премодерации |
| `comment_edit` / `comment_edit_no_moderations` | Редактировать свои комментарии (с модерацией / без) |
| `comment_delete` | Удалять свои комментарии |

Права выдаются в разделе **Пользователи → Группы** (кнопка «Права»).

### Настройки комментариев

Раздел **Настройки → Комментарии** (контроллер `comments`):

| Настройка | Значение |
|---|---|
| `max_depth` | Максимальная глубина вложенности ответов |
| `show_admin_badge` | Пометка «администратор» у автора-админа |
| `show_groups` | Показывать группу пользователя рядом с именем |
| `show_emodji` | Панель эмодзи в форме |
| `emodji_list` | Свой набор эмодзи |
| `z1`…`z16` | Служебные настройки формы (подписи, лимиты, поведение) |
| `color_badge`, `bg_badge`, `icon_badge`, `title_badge` | Оформление значков |

### Премодерация

Если у группы нет права `comment_add_no_moderations`, комментарий получает статус `pending` и ждёт одобрения. Из очереди модерации он выходит кнопкой «Одобрить» — или автоматически, если вы включите автоодобрение в настройках.

> [!WARNING]
> Не отключайте капчу и ограничение частоты (Настройки → Авторизация), если комментарии открыты для гостей: это первая цель спам-ботов. Движок поддерживает математическую, текстовую и графическую капчу, а также honeypot-поле.

## Итоговый чек-лист структуры

1. Категории созданы, у ключевых заполнены описания и картинки.
2. Теги не дублируют друг друга и не повторяют категории.
3. Для гостей и новых пользователей определена политика: писать ли комментарии и нужна ли премодерация.
4. В меню добавлены ссылки на важные категории — иначе читатель их не найдёт.
5. Проверены настройки отображения в **Настройках** соответствующих контроллеров.
