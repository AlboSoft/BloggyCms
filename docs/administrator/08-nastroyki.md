# ⚙️ Настройки

Раздел **Настройки** (`/admin/settings`) — центр управления движком. Здесь три вкладки: **Общие**, **Сайт** и **Компоненты** (настройки каждого модуля отдельно).

---

## Вкладка «Общие»

Базовые параметры сайта, которые влияют на весь фронтенд.

| Настройка | Ключ | Что делает |
|---|---|---|
| Название сайта | `site_name` | Заголовок в браузере, подписи, письма |
| Слоган | `site_tagline` | Короткая подпись сайта |
| Описание | `site_description` | Мета-описание по умолчанию |
| Автор | `site_author` | Мета-тег author |
| Ключевые слова | `meta_keywords` | Мета-тег keywords |
| Язык сайта | `site_language` | Язык фронтенда (`ru`, `en`, …) |
| Язык админки | `admin_language` | Язык панели управления |
| Часовой пояс | `timezone` | Для дат и времени |
| Форматы даты/времени | `date_format`, `time_format` | Как выводить даты |
| Фавикон | `favicon` | Иконка сайта |
| E-mail администратора | `admin_email` | Служебные уведомления |
| Контактный e-mail | `contact_email` | Публичный адрес для связи |
| Страница политики | `privacy_page` | Ссылка на страницу конфиденциальности |
| Регистрация открыта | `allow_registration` | Могут ли регистрироваться новые пользователи |
| Подтверждение e-mail | `user_email_verification` | Требовать ли подтверждение почты |
| Панель администратора на сайте | `show_admin_bar` | Показывать ли служебную панель |
| Sitemap / robots | `enable_sitemap`, `enable_robots_txt` | Генерировать ли файлы автоматически |
| **Режим отладки** | `debug_mode` | Записывать ошибки и показывать их в `/admin/debug` |
| **Режим обслуживания** | `maintenance_mode` | Закрыть сайт для всех, кроме админов |
| Сообщение обслуживания | `maintenance_message` | Текст для посетителей |
| Логирование | `error_logging`, `log_level` | Что и как подробно писать в логи |

> [!WARNING]
> **Режим обслуживания** отдаёт страницу 503 — это правильно для поисковиков, но не оставляйте сайт в нём «на всякий случай»: посетители уйдут.

## Вкладка «Сайт»

| Настройка | Ключ | Что делает |
|---|---|---|
| Тема оформления | `site_template` | Какая тема используется на фронтенде |
| Адрес сайта | `base_url` | Базовый URL (важно для писем и ссылок) |
| Резервные копии файлов шаблонов | `template_backups_enabled` | Сохранять предыдущие версии при правке через редактор |
| Сколько копий хранить | `template_backups_count` | Лимит на файл |
| Удалять старые копии | `template_backups_cleanup` | Автоочистка |

Кнопка **«Очистить резервные копии»** (`admin/settings/cleanup-backups`) удаляет накопленные `.backup.*`-файлы.

> [!TIP]
> Перед экспериментами с темой включите автобэкапы: правка одного файла в редакторе шаблонов может «сломать» сайт, а копия спасает за один клик.

## Вкладка «Компоненты» — настройки модулей

Каждый модуль движка может иметь собственные настройки: посты, комментарии, категории, SEO, авторизация, уведомления, админ-панель. Они собраны на вкладке **«Компоненты»**:

1. Выберите модуль в списке.
2. Заполните поля (движок сам строит форму из описания настроек модуля).
3. Сохраните.

Настройки хранятся в таблице `settings` под ключом `controller_<имя_модуля>`, например `controller_comments`, `controller_auth`, `controller_admin`.

### Что настраивается в популярных модулях

| Модуль | Примеры настроек |
|---|---|
| **Посты** (`posts`) | Что показывать на главной (`homepage_type`), постов на страницу, поведение 18+ (`adult_content_action`, `adult_min_age`), запоминать решение (`adult_remember_decision`) |
| **Комментарии** (`comments`) | Глубина ответов, значки, эмодзи, премодерация |
| **Категории** (`categories`) | Раскладка, количество на странице, показ описаний и картинок |
| **Теги** (`tags`) | Сколько тегов показывать на фронтенде |
| **Авторизация** (`auth`) | Капча, лимиты попыток, регистрация, восстановление пароля |
| **Уведомления** (`notifications`) | Уведомлять ли об ошибках и регистрациях |
| **Админ-панель** (`admin`) | Что показывать на дашборде, какие кнопки, логотип |

> [!NOTE]
> Модуль можно **отключить** целиком: `/admin/controllers`. Отключённые модули не отвечают на свои маршруты, но данные остаются в базе.

## Языки интерфейса

Раздел **Языки** (`/admin/language`) показывает доступные локали и позволяет править перевод. В поставке две локали: `ru_RU` и `en_En`.

- Язык админки задаётся настройкой `admin_language`.
- Язык фронтенда — `site_language`.
- Файлы переводов лежат в `/system/languages/<локаль>/` и разбиты по разделам: `core`, `controllers`, `fields`, `helpers`, `html_blocks`, `post_blocks`, шаблоны.

**Добавить язык:** скопируйте папку `en_En` в новую локаль (например, `de_DE`), переведите строки, выберите локаль в настройках. Подробнее — [Локализация](../developer/09-shortcodes-i-lokalizaciya.md#локализация).

## Иконки

Раздел **Иконки** (`/admin/icons`) — справочник доступных наборов: `bs` (Bootstrap Icons), `solid`, `regular`, `brands`, `emoji`, `icomoon`. Иконки используются в блоках, полях типа «иконка» и меню.

```php
<?php
// Вывод иконки в теме
echo bloggy_icon('bs', 'rocket-takeoff', 24, '#ff6b35');
```

## Сброс и обслуживание настроек

| Действие | Адрес | Осторожно |
|---|---|---|
| Сбросить настройки к значениям по умолчанию | `/admin/settings/reset` | Да — теряются ваши правки |
| Очистить бэкапы шаблонов | `/admin/settings/cleanup-backups` | Нет |
| Загрузить картинку для настроек | `/admin/upload/settings-image` | — |

> [!WARNING]
> Перед сбросом настроек сохраните резервную копию базы: настройки лежат в таблице `settings`, и восстановить их вручную непросто.
