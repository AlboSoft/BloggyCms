# 🔖 Шорткоды и локализация

Два инструмента, которые делают движок расширяемым без правки шаблонов: **шорткоды** — вставки в контент, **локализация** — все тексты интерфейса в языковых файлах.

---

# Шорткоды

Шорткод — короткая конструкция в тексте, которую движок заменяет на результат PHP-функции. Работают в постах, страницах, описаниях блоков, меню, фрагментах и HTML-блоках.

## Синтаксис

```text
{year}                        — одиночный шорткод
{field name="subtitle" type="post" id="12"}   — с атрибутами
{spoiler}Скрытый текст{/spoiler}              — парный (есть внутреннее содержимое)
{ctype:reviews}...{/ctype:reviews}            — шорткод с двоеточием в имени
```

Правила разбора:

- имя приводится к нижнему регистру;
- атрибуты — формата `ключ="значение"` или `ключ='значение'`;
- парные шорткоды обрабатываются первыми, затем одиночные;
- если шорткод не зарегистрирован — текст остаётся как есть (удобно для отладки).

## Регистрация своего шорткода

```php
<?php
// Где угодно — в хуках модуля, в init-файле, в экшене

Shortcodes::add('year', function ($attrs) {
    return date('Y');
});

// С атрибутами
Shortcodes::add('button', function ($attrs) {
    $text = $attrs['text'] ?? 'Подробнее';
    $url  = $attrs['url']  ?? '#';
    return '<a class="btn" href="' . html($url) . '">' . html($text) . '</a>';
});

// Парный шорткод: второй аргумент — содержимое между тегами
Shortcodes::add('spoiler', function ($attrs, $content = null) {
    if ($content === null) {
        return '';
    }
    return '<details class="spoiler"><summary>Показать</summary>'
         . Shortcodes::process($content)
         . '</details>';
});
```

Использование:

```text
© {year} Мой блог
{button text="Написать мне" url="/contacts"}
{spoiler}Здесь спойлер{/spoiler}
```

Возвращаемое значение:

| Что вернуть | Результат |
|---|---|
| Строку | Подставится вместо шорткода |
| `null` | Шорткод останется в тексте без изменений |

Дополнительно: `Shortcodes::has($name)`, `Shortcodes::remove($name)`, `Shortcodes::getAll()`, `Shortcodes::process($content)`.

## Встроенные шорткоды

| Шорткод | Что делает |
|---|---|
| `{field name="..." type="post" id="12" default="—"}` | «Сырое» значение пользовательского поля |
| `{field_display name="..." type="post" id="12"}` | Значение с учётом оформления типа |
| `{<сущность>_<системное_имя>}` | Автошорткод активного поля: `{post_subtitle}`, `{page_phone}` |
| `{fragment:<system_name>}` | Вывод фрагмента |
| `{<system_name>}` | То же, короткая форма (`{reviews}`) |
| `{ctype:<system_name>}...{/ctype:<system_name>}` | Вывод фрагмента с собственным шаблоном |
| `{menu ...}` | Вывод меню (`render_menu_by_id`, `render_menu_by_name`) |

Примеры:

```text
Цена: {field name="price" type="post" id="42" default="по запросу"}
{post_rating}
{fragment:reviews}
{ctype:partners}<a href="{url}">{name}</a>{/ctype:partners}
```

> [!TIP]
> Список подстановок, доступных в шаблоне конкретного пост-блока, возвращает метод `getShortcodes()`. Если вы дописали подстановку — добавьте её в этот список, и администратор увидит подсказку в редакторе.

# Локализация

Все тексты интерфейса в BloggyCMS — константы `LANG_*` в языковых файлах. Никаких строк «в лоб» в шаблонах: иначе перевод станет невозможен.

## Структура

```text
system/languages/
├── ru_RU/                    # локаль по умолчанию
│   ├── core/                 # ядро
│   │   ├── Controller.php
│   │   ├── BasePostBlock.php
│   │   └── ...
│   ├── controllers/          # модули
│   ├── fields/               # пользовательские поля
│   ├── helpers/              # хелперы
│   ├── html_blocks/          # HTML-блоки
│   ├── post_blocks/          # пост-блоки
│   └── templates/            # шаблоны темы
└── en_En/
    └── ... (та же структура)
```

Файл — это обычный PHP с `define()`:

```php
<?php
// system/languages/ru_RU/controllers/posts.php
define('LANG_CONTROLLER_POSTS_MANIFEST_NAME', 'Посты');
define('LANG_CONTROLLER_POSTS_SETTINGS_POSTS_PER_PAGE', 'Постов на странице');
define('LANG_ACTION_POSTS_INDEX_PAGE_TITLE', 'Все посты');
```

Использование:

```php
<?php // в PHP
echo LANG_CONTROLLER_POSTS_MANIFEST_NAME;

<?php // в шаблоне
<h1><?= LANG_ACTION_POSTS_INDEX_PAGE_TITLE ?></h1>
```

## Именование констант

Схема, принятая в проекте:

```text
LANG_<ОБЛАСТЬ>_<МОДУЛЬ>_<ЧТО>
```

| Префикс | Где живёт |
|---|---|
| `LANG_CORE_*` | Ядро (`system/core/`) |
| `LANG_CONTROLLER_<МОДУЛЬ>_*` | Данные модуля: манифест, настройки |
| `LANG_ACTION_<МОДУЛЬ>_<ЭКШЕН>_*` | Строки экшенов |
| `LANG_TEMPLATE_<МОДУЛЬ>_*` | Шаблоны темы |
| `LANG_HELPER_*` | Хелперы |
| `LANG_FIELD_*` | Поля |
| `LANG_POSTBLOCK_*`, `LANG_HTMLBLOCK_*` | Блоки |

> [!TIP]
> Название файла языковых строк совпадает с местом, где они используются: `controllers/posts.php`, `post_blocks/QuoteBlock.php`. Так проще найти нужную константу.

## Как движок выбирает язык

1. Если в сессии есть `admin_language` (язык админки) — берётся он.
2. Иначе `user_language`.
3. Иначе для `/admin/*` — настройка `general.admin_language`, для фронтенда — `general.site_language`.
4. Если папки локали нет — используется `ru_RU`.
5. Догружаются языковые файлы темы: `templates/<тема>/languages/<локаль>/`.

**Важно:** значение настройки должно совпадать с **именем папки** локали: `ru_RU`, `en_En`.

## Как добавить новый язык

1. Скопируйте папку-образец:

```bash
cp -r system/languages/en_En system/languages/de_DE
```

2. Переведите строки в файлах (значения `define(...)`, ключи не трогайте).
3. В админке: **Настройки → Общие** → `site_language` = `de_DE` (и `admin_language`, если нужен немецкий интерфейс админки).
4. Проверьте фронтенд и админку: непереведённые строки будут видны как имена констант — это удобно для поиска пропусков.

> [!NOTE]
> Контент сайта не переводится автоматически: локализация касается интерфейса движка и темы. Мультиязычный контент реализуется отдельными сущностями (разные посты/страницы) или своим модулем.

## Хелперы для текста

| Функция | Назначение |
|---|---|
| `plural($n, [$one, $few, $many])` | Склонения: `1 комментарий`, `2 комментария` |
| `format_date($date)` | Дата с названием месяца из локали |
| `time_ago($date)` | «5 минут назад» |
| `truncate($text, $length)` | Обрезка с многоточием |
| `html($value)` | Экранирование |

> [!WARNING]
> Не подставляйте переведённые строки в SQL, JavaScript без экранирования или в имена файлов. Переводы — только для вывода.
