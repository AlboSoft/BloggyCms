# 📚 Документация BloggyCMS

Добро пожаловать! Здесь собрана полная документация движка **BloggyCMS** — от установки до написания собственных модулей.

## 📐 Соглашения документации

- Пути указываются от корня сайта: `/system/core/Event.php` — файл движка, `/templates/default/front/layout.php` — файл темы.
- Код в примерах — рабочий. Копируйте и адаптируйте под свои задачи.
- `{...}` в примерах шорткодов — синтаксис самого движка, а не заполнитель (например, `{post_subtitle}`).
- Всё, что помечено значком 💡 — подсказка, ⚠️ — предупреждение, 🚫 — так делать не нужно.
